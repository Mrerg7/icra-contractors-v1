# icra.contractors

Premium domain acquisition landing page for **icra.contractors** — the network brand for Infection Control Risk Assessment (ICRA) contractors in healthcare construction.

## Stack

- [Astro](https://astro.build) static site
- Tailwind CSS
- Cloudflare Workers (assets + edge redirects / security headers)

## Local development

```bash
npm install
npm run dev
```

App runs at [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Build & deploy

```bash
npm run build
npm run deploy
```

Production URL: [https://icra.contractors/](https://icra.contractors/)

Cloudflare Workers Builds deploys automatically when changes land on `main`.
